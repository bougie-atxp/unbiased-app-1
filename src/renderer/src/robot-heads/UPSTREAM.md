# Robot Head Source

Vendored from [fayazara/robot-heads](https://github.com/fayazara/robot-heads/tree/58ebf6439a8125a769f63b22ffd35bc18834b1b5/src)
at commit `58ebf6439a8125a769f63b22ffd35bc18834b1b5` under the MIT license in
`LICENSE`.

Unbiased adds a controlled `direction` prop to turn the head during desktop
window drags, including while the agent is working. The original pointer and
state animations are otherwise retained.
